# FTPlink - FTP & SFTP 网络存储浏览器

支持 FTP / SFTP 协议的网络存储浏览器，文件可预览，白名单外的文件调用系统原生打开方式。

## 功能

- 🌐 FTP / SFTP 连接管理
- 📁 文件浏览器（支持导航、复制、粘贴、删除、重命名）
- 📂 新建文件夹
- 🔍 文件预览（图片、视频、文本等）
- 📤 系统打开方式（白名单外文件）
- 🗑️ 回收站
- ⚙️ 可自定义缓存区大小

## 技术栈

- Kotlin + Jetpack Compose
- MVVM + Clean Architecture
- Hilt 依赖注入
- Apache Commons Net (FTP)
- JSch (SFTP)
- Material Design 3
